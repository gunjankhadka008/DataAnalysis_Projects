## Project Overview
This project analyzes customer spending patterns to understand the relationship between total bill amounts and group sizes. The goal was to build a machine learning model to predict the number of people in a group based on their transaction value.

## Tech Stack
- **Language:** Python
- **Data Manipulation:** Pandas
- **Visualization:** Seaborn, Matplotlib
- **Machine Learning:** Scikit-Learn (Logistic Regression)

## Results
- **Key Insight:** Identified distinct spending distributions between Lunch and Dinner shifts
- **Model Performance:** 71% accuracy in predicting group sizes
